Design Critique

让站点更靠近 National Geographic Travel

目前站点已经具备杂志感的雏形,但整体读起来更像"深色封面 + 米色内页的作品集", 与 NatGeo Travel 的"白底 + 大衬线 + 照片自己负责所有暗色"还隔着几条具体的规则。 以下是基于现状的对照清单和改造路径。

NatGeo 的视觉基因(参照系)

  1. 白底为主,几乎不出现整块深色 section;照片自己负责"暗"。
  2. 黄色只用在 logo 那个矩形和极少的提示色,不充当大面积装饰。
  3. 大字号衬线标题(自家的 Geograph),收紧的字距,配窄一点的 sans 做小标签。
  4. 首页是杂志格栅:一条头条 + 多条次级故事,而不是一张全屏 hero。
  5. 每个故事都有署名 / 日期 / 阅读时长 / 类别,提供阅读锚点。
  6. 照片下永远有摄影师署名 —— NatGeo 的精神图腾。
  7. 分隔线是 1px hairline,几乎没有粗边框。
  8. 排版克制,留白巨大,几乎不用阴影、圆角、渐变叠层(除非是照片底部的可读性遮罩)。

当前站点与 NatGeo 偏离的地方

1. 顶栏方向反了 ⚠️ 影响最大

styles.css:38 现在是深色 sticky header + 4px 金色底边, 这是 Vox / Eater / The Verge 的语言。NatGeo 顶栏是 纯白底 + 黑字 + 左上一个 NatGeo 黄色矩形 logo。

→ 改成白底黑字、去掉 border-bottom: 4px solid var(--gold), 品牌处放一个 24×8 左右的黄块作为 logo。整体气质会立刻往 NatGeo 靠。

2. 首页 Hero 太"作品集"

renderIndex() 把一张照片拉满屏 + opacity:0.62 + 黑色渐变 + 居中标题,这是摄影师个人站的范式。 NatGeo 首页是格栅:一条 lead story(大图 + 标题在图下方,而不是覆盖在图上) + 4–6 条次级 story。

→ 把 .home-hero 改成"一张大图,标题/导语在图下面的白色区域"。 这一动就脱离了 portfolio 味。

3. 大面积深色 section 与 NatGeo 冲突

styles.css:194 把 "Selected" 一栏整块翻成 #151515。 NatGeo 几乎不会这样做 —— 它让深色发生在照片本身,而不是版面背景。

→ 这个 section 改成白底,文字在图旁边,只让照片暗。 或者完全删掉这一区块,合并到上方主题网格里。

4. 排版:衬线选错了一档

  • font-family: Georgia 是合格的兜底,但 Georgia 的笔画偏胖、 x-height 偏大,跟 NatGeo Geograph 的"瘦高、锐利、收紧"完全不是一个性格。
  • Inter 在 font-family 里写了 但没有 <link> 载入,实际渲染是 system-ui。

→ 引入 Google Fonts:Source Serif 4 或 EB Garamond / Spectral 做标题, Inter 或 IBM Plex Sans 做正文/小标签, 并真正 <link> 进来。标题加 letter-spacing: -0.01em,会立刻"瘦"下来。

5. Eyebrow 小标签上的金色短条

styles.css:152 的 .eyebrow::before 画了一条 34×4 的金色横杠 —— 这是 Vox 的标志性元素,NatGeo 没有这种"前缀杠"。

→ 删掉伪元素,留下纯 uppercase tracked 文本(letter-spacing: 0.14em 左右), 颜色用红或深灰即可。

6. 卡片底部 4px 黑色粗边

styles.css:234 border-bottom: 4px solid var(--ink) 是 Bloomberg / FT 的语言,NatGeo 不用;它用 1px hairline 或干脆无边。

→ 删掉这条边,改成 hover 时图片轻微 scale(1.02) + 标题底部出现细下划线。

7. 按钮太"主题模板感"

styles.css:159 黄底黄边 + 粗体大写,像 Awesome 风 WordPress theme。 NatGeo CTA 通常是小写、细线、底部短下划线("Read the story →") 或一个朴素的描边小药丸。

→ 改成下划线文本链接或细描边按钮,字号 13–14。

8. 卡片信息缺"署名 / 日期 / 时长"

现在 region/story card 是 [kicker → title → deck]。 NatGeo 是 [kicker → title → BY 张三 · 日期 · 5 min read]。

→ 数据里给每条 story 加 byline(可以填"摄影 / 文字 + 你的名字") 和 readMinutes,卡片底部和 hero 下方都展示。

9. 照片缺图注 / 署名

NatGeo 每张大图正下方都有一行 Photograph by X 的小灰字。 你的 .photo-story / .theme-photo 里只有 location · date。

→ 在主图 <img> 后加一个 <figcaption>, 小号、color: var(--muted)、font-size: 12px, 可以写"摄影:你的名字 · 镜头型号 / 地点"。一行字,杂志感立刻立起来。

10. 红色用得太频繁

--red: #9a2f24 被用在 kicker、meta、card span 三处, 几乎每个小标签都是红的。NatGeo 的红只在"trending / 推荐"上偶尔出现,常态是黑或灰。

→ kicker 用黑或深灰,只在地区分类标签(像"成都"那种)用一次红色。

11. Section 标题双列布局可以保留

styles.css:208 用 border-top: 1px hairline + padding-top: 22px 是对的方向,这一点已经很 NatGeo。 但 .section--dark 本身不该存在(见 #3)。

12. 移动端汉堡 / 抽屉缺失

现在 @media (max-width:860px) 把 nav 改成横向滚动条。 NatGeo 移动端是左上汉堡菜单 + 全屏抽屉。 横向滚动 nav 在内容多时会显得很乱。

→ 中长期换成 hamburger drawer。

13. 缺少"杂志小元素"

NatGeo 的高级感很多来自这些细节:

  • 文章开头一个 drop cap(首字下沉的大写字母)。
  • 段落中间有一条细短水平线做章节分隔。
  • 引文用超大斜体衬线 pull quote,左侧黄色短竖线 (就像本页下面这段示意一样)。
NatGeo 是"白底 + 大衬线 + 照片自己负责所有暗色", 而你现在的站是"米色底 + 深色块 + 金色装饰条"。

→ 主题页 renderTheme() 的 theme.intro 那段, 完全可以套这套排版。

改造优先级

优先级改动收益
P0 顶栏白底化、去掉 4px 金线、加黄色矩形 logo 一眼就像 NatGeo
P0 首页 hero 改为"图下标题"的杂志格栅 摆脱作品集观感
P0 真正加载一对衬线 + sans 字体 整站气质
P1 给每张照片加 figcaption(摄影署名) 杂志精神
P1 删掉 .section--dark 翻转区块 视觉统一
P1 卡片去除粗黑底边,改 hover 微动效 轻盈
P2 数据加 byline / readMinutes 信息密度
P2 drop cap / pull quote / hairline 章节线 阅读质感
P2 红色降级,只留少量场景 调色克制
最关键的一句话: 把"米色底 + 深色块 + 金色装饰条"拨回到"白底 + 大衬线 + 照片自己负责所有暗色", 就完成了 80% 的风格靠拢。其余的署名、drop cap、hairline,是把它从 80 推到 95 的细节。
本页本身的样式即按上述建议写成:白底、左上黄块 logo、衬线大标题、hairline 分隔、 左侧黄色短线的 pull quote。可以作为后续改造 styles.css 的视觉锚点。
